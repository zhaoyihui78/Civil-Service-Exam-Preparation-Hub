# 考公知识库（Synthetic Demo）

这是与 `Workbench/` 并列、可以独立打开和替换的示例考公知识库。默认内容聚焦公务员考试、岗位筛选、行测、申论、面试，以及马克思主义理论在政策分析和申论表达中的应用；人物、项目、文章、作品、数据与时间均从零虚构，不对应任何真实账号或个人。

示例 Wiki 只使用两类页面：

- `wiki/concepts/`：解释稳定概念
- `wiki/frameworks/`：保存可重复执行的方法

Workbench 在没有环境变量时默认读取本目录。连接自己的 Vault 时，可以用 `PERSONAL_DASHBOARD_VAULT_ROOT` 指向另一个目录；不要把本目录中的示例内容当作知识结论。
